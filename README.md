# Toolbox.Dapper.SQLite
Wrapper around Dapper for SQlite databases that have all tables with autoincrement id.
Provide statement generation for standard SELECT, INSERT, UPDATE and DELETE statements.

See documentation at https://Calteo.github.io/Toolbox.Dapper.SQLite/
